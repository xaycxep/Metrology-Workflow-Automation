Запустите editor.py
В появившемся диалоге выберите ZIP-архив, содержащий PDF-свидетельства.
Скрипт:

Извлекает все PDF;

Находит на каждой странице фразу «должность руководителя или» и вычисляет координаты;

Накладывает текст (регистрационный номер, ФИО поверителя, должность);

Сохраняет объединённый PDF как output_files.pdf и отправляет его на печать через SumatraPDF.
