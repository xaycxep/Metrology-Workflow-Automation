# Metrology-Workflow-Automation
## Описание

Проект создан для автоматизации рутинных задач метрологической лаборатории. Он включает в себя:

- Чтение данных из Excel-реестров;
- Генерацию XML-файлов для импорта в **ФГИС АРШИН**;
- Автоматическое заполнение **протоколов поверки**;
- Создание **свидетельств о поверке** с наложением текста и отправку на печать;
- Формирование **отчётов для ФСА**;
- Ведение локальной **базы данных SQLite** со всеми записями поверок;
- Пакетную обработку **счетов и квитанций** через VBA в Excel.

## Требования

- **Python 3.8+**
- **Microsoft Excel** (для работы с COM-объектами и VBA)

### Основные Python-библиотеки:

- `sqlalchemy`
- `pywin32` (для взаимодействия с Excel)
- `reportlab`, `PyPDF2`, `fitz` (PyMuPDF) – для работы с PDF
- `requests` – для API-запросов
- `xml.etree.ElementTree`, `minidom` – встроенные
