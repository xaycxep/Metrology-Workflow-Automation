# Metrology-Workflow-Automation
Генерация XML для ФГИС АРШИН – создание файлов импорта по результатам поверки. Создание протоколов поверки – автоматическое заполнение Excel-шаблонов. Экспорт в PDF и печать – наложение текста на свидетельства, работа с ZIP-архивами, отправка на печать.Отчёты для ФСА – получение данных о поверках через API АРШИН, формирование XML-отчёта.
