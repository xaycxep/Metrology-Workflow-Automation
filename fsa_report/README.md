Скачиваете Excel-файл с АРШИНа
Добавляете колонку справа и вписываете по каждой позиции фамилии, предварительно добавив их в SNILS_DATA
Запускаете xml_generator.py
В диалоге выберите ранее загруженный Excel-файл

Скрипт:
По каждому номеру делает запрос к API АРШИН (https://fgis.gost.ru/fundmetrology/eapi/vri);
Извлекает даты поверки, окончания, наименование СИ;
По фамилии поверителя подставляет СНИЛС из словаря;
Формирует XML-файл для импорта в ФСА и сохраняет его как example.xml. (имя можно другое придумать)
